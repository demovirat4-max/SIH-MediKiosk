# MediKiosk - Patient Intake & Clinical Triage Kiosk

A complete, production-ready Next.js application for **MediKiosk**, converted directly from exported Stitch UI screens into functional React components with working state, speech-to-text, Gemini AI clinical reasoning, Tesseract.js OCR, deterministic red-flag triage, and React Context + LocalStorage queue management.

---

## Key Features

1. **Stitch UI Design System Fidelity**:
   - Built with Tailwind CSS using the exact tokens from `DESIGN.md` (`Plus Jakarta Sans`, `Inter`, `Material Symbols Outlined`, clinical sky-blue/teal palette, tactile kiosk elevation, and pill-shaped curves).
   - Cleaned up top navigation on all screens: persistent links removed in favor of a clean logo and step indicator badge.
   - Cleaned up physician summary & red-flag screens: removed fabricated vitals sensors and fabricated nurse dispatches, replaced with authentic AI-derived triage summaries and clean notification feedback.

2. **Full End-to-End User Journeys**:
   - **Role Selector (`/`)**: Patient vs. Doctor touch cards + bilingual voice help.
   - **ABHA Entry (`/patient/abha`)**: Tactile on-screen numeric kiosk keypad (and physical keyboard support), 2-4-4-4 digit formatting, and "Skip / I don't have ABHA" guest intake.
   - **Consent (`/patient/consent`)**: Reassuring clinical consent with voice synthesis playback and trust assurances.
   - **Mode & Language (`/patient/mode-language`)**: Dual consultation stream (Allopathy vs. AYUSH) + regional language selector chips (Hindi, English, Bengali, Marathi, Telugu, Tamil).
   - **Voice & Touch Intake (`/patient/questionnaire`)**:
     - Browser-native **Web Speech API** for multilingual speech-to-text.
     - Conversational logic: **Gemini API (`gemini-2.0-flash`)** dynamically crafts SOCRATES follow-up questions for Allopathy or Prakriti/Vikriti/Agni questions for AYUSH with tappable option cards.
     - Built-in clinical fallback if no API key is provided, ensuring 100% uptime.
     - **Deterministic Red-Flag Detection**: Instant local keyword matching for acute emergencies (chest pain, breathing difficulty, severe bleeding, loss of consciousness).
   - **Red-Flag Alert (`/patient/red-flag`)**: Critical priority triage with Emergency Token `#E-09`, AI-derived alert explanation, "A staff member has been notified" notification, and synthesized emergency bell chime.
   - **Document Scan (`/patient/scan`)**: Camera viewfinder with animated laser sweep, corner guides, and client-side **Tesseract.js OCR** to extract text from prescription slips or gallery uploads.
   - **Extracted Document Review (`/patient/review`)**: Side-by-side paper preview and verified health readings (voice intake, AI triage, OCR findings) with one-tap token generation.
   - **Confirmation Screen (`/patient/confirmation`)**: OPD Token Platter (e.g. `#A-43`), room assignment, thermal paper slip print animation, and countdown redirect.
   - **Doctor Sign-In (`/doctor/login`)**: Mobile number or Hospital Staff ID tabs with 800ms verifying simulation.
   - **Physician Dashboard (`/doctor/dashboard`)**: Dr. Rajesh Kumar, MD, Room 12 queue view with triage status badges (`Urgent Triage`, `Review Needed`), real-time wait times, and persistent patient list.
   - **Physician Summary (`/doctor/summary/[id]`)**: Full structured clinical documentation generated by Gemini (Chief Complaint, HPI, Past History, Drug/Allergy, Family/Social, ROS, OCR Investigation Values) with "Accept Patient / Call In" chime.

## Environment Configuration

Create or update `.env.local` in the project root:

```env
# Optional: Google Gemini API key for dynamic AI follow-up questions & summaries
# Get your free key at https://aistudio.google.com/
GEMINI_API_KEY=your_gemini_api_key_here
```

> **Note**: Even if `GEMINI_API_KEY` is omitted, the app operates seamlessly using our built-in local clinical heuristic engines for both Allopathy and AYUSH streams.

## Getting Started

### Development Mode

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
